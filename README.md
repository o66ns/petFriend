## 📌 About the Project
**Petfriend** is a web application for an animal shelter where users can browse animals and filter them by different criteria.
Authorized users can also add animals to favorites and create new animal cards or delete them.

---

## ✨ Features
- 📋 Browse the animal catalog  
- 🔍 Filter by:
  - type  
  - age  
  - color  
  - gender  
  - (and more criteria)  
- ➕ Add a new animal (**authorization required**)
- 🗑 Delete an animal card  
- ❤️ Add animals to favorites (**authorization required**)
- ❌ Remove from favorites  
- 📄 View detailed animal information

## 🚀 Installation & Setup

### 1. Clone the repository (terminal: bash/powershell/...)
```
git clone https://github.com/o66ns/petFriend.git
cd petFriend
```
### 2. Install dependencies
```
npm install
```
### 3. Run the frontend
``` 
cd petfriend
npm run dev
```
### 4. Run the backend
```
cd backend
npm run dev
```
### 5. Open in browser
http://localhost:5173

### Or run with docker (Docker instalation needed)
```
docker-compose up --build
```
