## 📌 About the Project
**Petfriend** is a web application for an animal shelter where users can browse animals and filter them by different criteria.
Authorized users can also add animals to favorites and create new animal cards or delete them.

---

## ✨ Features
- 📋 Browse the animal catalog  
- 🔍 Filter by:
  - type  
  - age  
  - color  
  - gender  
  - (and more criteria)  
- ➕ Add a new animal (**authorization required**)  / Delete a card
- ❤️ Add animals to favorites  
- ❌ Remove from favorites  
- 📄 View detailed animal information
